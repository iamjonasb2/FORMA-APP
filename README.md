# Kraftpfad

Kraftpfad ist eine deutschsprachige Trainings-Web-App.

## Varianten

- `index.html` – lokal startbare Web-App mit gebündelter `three.min.js`.
- `pwa/` – installierbare Offline-Web-App mit eigenem Manifest, Service Worker und App-Symbolen.

Die PWA muss einmal über HTTPS geöffnet werden. In Safari auf dem iPhone: **Teilen → Zum Home-Bildschirm**. Übungsbilder können in der App für den Offline-Betrieb zwischengespeichert werden.

Trainingsdaten werden lokal im Browser gespeichert und nicht mit einem Server synchronisiert.
