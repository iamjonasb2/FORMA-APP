# Kraftpfad Offline-PWA

Diese Variante ist für Installation auf dem iPhone vorbereitet. Einmal über HTTPS öffnen; danach funktioniert die App-Oberfläche offline.

1. In Safari öffnen.
2. Teilen → Zum Home-Bildschirm.
3. In Konto → Übungsbilder offline speichern.

3D-Bibliothek und App-Dateien werden lokal zwischengespeichert. Übungsbilder werden nach dem Download ebenfalls offline verfügbar. Coach-Modell und externe Videolinks benötigen eine Internetverbindung. Trainingsdaten bleiben lokal im Safari-Web-App-Speicher.
